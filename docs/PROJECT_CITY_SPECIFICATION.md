### 2.1 Skyscraper 01: LorryBook / RDA Logistics Tower
- **Coordinates**: `[52, 8, -20]`
- **Theme**: Freight & Dispatch Allocation Platform
- **Architecture**:
  - 3-tier stepped obsidian tower (`[8, 10, 8]` base, `[6.5, 8, 6.5]` mid, `[5, 5, 5]` crown).
  - Vertical neon crimson edge conduits (`#FF3358`).
  - High-gain telemetry antenna mast with a rotating logistics dispatch beacon.
- **Underlying Project**:
  - Event-driven dispatch architecture combining geofenced driver availability matching queues with digital proof-of-delivery reconciliation.
  - Built with Python, PostgreSQL, FastAPI, and Leaflet.
  - Verified Repository: `https://github.com/santhoshkumariicse-gif/rda`.

### 2.2 Skyscraper 02: NexusATS Pipeline Center
- **Coordinates**: `[70, 8, -32]`
- **Theme**: AI Resume Parsing & Candidate Stage-Gate Pipeline
- **Architecture**:

- **Underlying Project**:

  - Built with Python, FastAPI, SQLite / JSON Schema, and Regex triage.
  - Verified Repository: `https://github.com/santhoshkumariicse-gif/portfolio`.
