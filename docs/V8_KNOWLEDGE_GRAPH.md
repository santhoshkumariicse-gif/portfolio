# Portfolio V8: Interactive Technical Knowledge Graph (Prompt 45)

## 1. Relational Model & Architecture
In accordance with **Prompt 45 (Technical Knowledge Graph)**, the portfolio integrates an interactive skills and technology knowledge graph at `#knowledge-graph`.

The graph moves away from subjective, arbitrary "proficiency percentage bars" (e.g. "Python 95%") and instead models real technological interdependencies:
- **Node-Link Topology**: 13 primary technologies across Languages, Backend, Security, Frontend, and Tools.
- **Relational Edges**: Illustrates how languages bind to web frameworks (e.g. `Python 3` -> `FastAPI`), how frameworks enforce defensive security rules (`FastAPI` -> `SQLi Defense`), and how guidelines mitigate attack surfaces (`OWASP Top 10` -> `XSS Encoding`).

---

## 2. Interactive Capabilities
1. **Node Selection & Neighbor Highlighting**: Selecting any node automatically highlights all directly connected dependencies and companions with electric-lime signal paths.
2. **Real Project Provenance**: The inspection card highlights verified projects where Santhosh has applied the selected technology.
3. **Keyword Search & Category Filtering**: Quick text filtering across skill names, categories, and descriptions.
4. **Accessible Dual-Mode Display**: A dedicated "Accessible List" toggle presents the entire network in accessible card format for low-motion and screen-reader accessibility.
